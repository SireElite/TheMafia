Небольшая мафия, где вы играете с ботами.

Имеется 5 ролей - мирный, шериф, мафия, доктор и путана. У разных ролей разная логика голосования:

Ночное голосование:
- Мирный ночью не ходит.
- Мафия рандомно выбирает игрока (кроме самой мафии).
- Шериф рандомно выбирает того кого ещё не проверял.
- Доктор и путана могут пойти только к тому, кого не лечили прошлой ночью.

Дневное голосование:
- Мирный, доктор и путана голосуют рандомно.
- Мафия выбирает рандомного игрока (кроме самой мафии).
- Если шериф нашёл хоть одну мафию, то будет голосовать в неё до конца, если шериф нашёл больше 1 мафии, то случайным образом выбирает одну и голосует в неё, если шериф нашёл мирного, то не будет голосовать в него до конца игры.
